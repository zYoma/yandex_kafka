# Yandex Kafka Consumer

## Описание

Yandex Kafka Consumer - это приложение для обработки сообщений из Apache Kafka с использованием Go. Приложение поддерживает два режима работы: одиночное сообщение (SingleMessage) и пакетная обработка (BatchMessage).

## Архитектура

### Основные компоненты

1. **KafkaConsumer** - основной класс для работы с Kafka
   - Подключение к Kafka кластеру
   - Обработка сообщений в двух режимах
   - Управление offset'ами
   - Логирование событий

2. **Domain** - доменные объекты
   - Product - модель продукта
   - ProcessProducts - функция обработки пачки продуктов

3. **Application** - точка входа приложения
   - Инициализация консьюмера
   - Запуск обработки сообщений

### Принцип работы

#### SingleMessage режим
- Обрабатывает сообщения по одному
- Использует автоматическое управление offset'ами Kafka
- Подходит для простых случаев обработки

#### BatchMessage режим
- Собирает сообщения в пачки заданного размера
- Обрабатывает пачки параллельно в горутинах
- Поддерживает ручное управление offset'ами
- Обеспечивает отказоустойчивость через механизм rollback/commit

## Запуск приложения

### Требования
- Docker и Docker Compose
- Go 1.21+
- Apache Kafka кластер (или Docker-контейнеры)

### Шаги запуска

**Запуск с помощью Docker Compose:**
```bash
make run
```

3. **Запуск вручную:**
```bash
# Запустить консьюмер
./yandex-kafka-consumer consumer

# Запустить продюсер для тестирования
./yandex-kafka-consumer producer
```

## Настройка окружения

### Переменные окружения

- `ENABLE_SINGLE_MESSAGE_CONSUMER` - включить режим одиночного сообщения (true/false)
- `GROUP_ID` - ID группы потребителей Kafka
- `GROUP_INSTANCE_ID` - уникальный ID экземпляра группы
- `BATCH_SIZE` - размер пачки сообщений для Batch режима
- `BATCH_TIMEOUT_MS` - таймаут ожидания пачки в миллисекундах

### Конфигурация Docker Compose

Файл `docker-compose.yml` содержит конфигурацию для запуска:
- 3 Kafka брокера
- Schema Registry
- 2 консьюмера (consumer-1 и consumer-2)
- Продюсер для тестирования

## Проверка работы

### Шаги проверки

1. **Проверка запуска контейнеров:**
```bash
docker-compose ps
# Все контейнеры должны быть в состоянии Up
```

2. **Проверка логов:**
```bash
# Логи консьюмера
docker logs -f yandex-kafka-consumer-2-1
docker logs -f yandex-kafka-consumer-2-2

# Логи продюсера
docker logs -f yandex-kafka-consumer-producer
```

3. **Проверка обработки сообщений:**
   - В логах должны появляться сообщения вроде:
     ```
     Got 10 messages from partition 0: [product1 product2 ...]
     коммитим offset 1065, партиция 0
